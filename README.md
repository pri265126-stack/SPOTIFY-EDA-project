# Spotify EDA Project 🎵

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a Spotify songs dataset using Python. The goal is to understand song popularity, danceability, energy, genres, artists, and the relationships between audio features.

## Tools & Libraries Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset Information
- Total Rows: 6097
- Total Columns: 20 (after removing the `Unnamed: 0` column)

## Analysis Performed
- Data loading and cleaning
- Missing value handling
- Dataset information and statistical summary
- Popularity distribution
- Danceability distribution
- Energy distribution
- Box Plot
- Scatter Plot
- Correlation Heatmap
- Top 10 Genres
- Top 10 Artists
- Top 10 Most Popular Songs
- Top Genres by Average Popularity

## Key Insights
- Most songs have medium popularity.
- Most songs have high energy and moderate danceability.
- Energy and Loudness show a strong positive correlation.
- Anime has the highest average popularity among genres.
- The Beatles have the highest number of songs in this dataset.

## Conclusion
This EDA project helps understand Spotify song trends through data cleaning, statistical analysis, and visualizations.
